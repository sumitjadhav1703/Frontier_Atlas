# Source register and research notes

Desk research performed 21 November 2026. These pages identify real candidates and documented interfaces. A landing page opening in a browser does not establish extraction permission, original publication timestamps, free quota, endpoint stability or enough qualifying records. Record the live result per route in B8. Keep discovery, canonical origin and enrichment URLs separate.

## Bulk routes

| Vertical | Primary and fallback route | First live probe and switch condition |
| --- | --- | --- |
| Startups | Use the unofficial YC OSS AI-tag JSON as discovery. Stream the JSON array or batch files, keep the original YC profile and source ID, preserve exact AI tag and team-size evidence. Broaden to adjacent ML/generative-AI tags with strict relevance and ID deduplication. Official YC AI directory is an independent discovery/check path. | Look at 30 distinct rows across source partitions. Count accessible original evidence, duplicate IDs, explicit headcounts and eligible AI companies. A tag page’s headline count is only a lead. If licensed discovery or evidence fails, use permitted official organization pages and a second documented directory. [YC OSS inventory](https://github.com/yc-oss/api/blob/main/README.md) · [YC AI directory](https://www.ycombinator.com/companies/industry/artificial-intelligence) |
| Products | Start with AgiPicks’ attributed open product JSON. Deduplicate to products, carry license and attribution, follow vendor evidence for owner and pricing. Use FutureTools’ browse directory for additional leads where access is permitted and YC companies’ official product/pricing pages for the gap. A plan-level CSV can have many rows per product. | Pilot 30 products across free, trial, paid and unknown; project verified owner+pricing yield. Measure overlap across candidate pools. Switch early if remaining unique candidates × observed acceptance rate cannot cover outstanding target plus 20% reserve. Record the owner spelling separately from the product name. [AgiPicks data and license](https://agipicks.com/data/) · [FutureTools](https://futuretools.io/) |
| Paper identities and repo edges | Start from pinned Papers with Code archive partitions. Join paper→repo edges to paper metadata by documented IDs/URLs, prefer explicitly official links. Corroborate arXiv metadata including original submission date and authors in batches. An archive date without time does not justify midnight as a publication instant. Fallback to direct code links in the paper or author project page. | Sample 30 edges including multi-repo, missing arXiv IDs, dead repos and helper libraries. Capture file revision/checksum, association evidence and publication field. Refill from the next partition until 1,000 unique papers qualify. The employer’s .co example links several libraries and is labeled an external resource; exclude it if authors, paper URL or primary code cannot be evidenced. [Archive index](https://github.com/paperswithcode/paperswithcode-data) · [Paper metadata](https://huggingface.co/datasets/pwc-archive/papers-with-abstracts) · [Repo edges](https://huggingface.co/datasets/pwc-archive/links-between-paper-and-code) · [Example](https://paperswithcode.co/paper/98456) · [arXiv terms](https://info.arxiv.org/help/api/tou.html) |
| Paper metadata (B8 live route, 2026-11-23) | Page only `pwc-archive/links-between-paper-and-code` datasets-server `/rows` (official, arXiv-ID, github.com rows; paced 3.2 s/GET, 429 back-off), then resolve title/authors/date from the OpenAlex works API by arXiv DOI `10.48550/arxiv.<id>` (CC0, robots `Allow: /`, no key or mailto sent). Works merged into a published version are matched through their arXiv location. Missing work, title, authors or date → quarantine `missing_paper_metadata`. | `/filter` returned "dataset index is loading" for both datasets on 2026-11-22/23, and a random `/rows` join with papers-with-abstracts had no locality. Probe 2026-11-23: 2 link pages → 55 arXiv papers; 1 OpenAlex batch of 50 → 50 complete. Published date is OpenAlex `publication_date` (day precision; may be the journal date for merged works). [OpenAlex works API](https://docs.openalex.org/api-entities/works) |
| GitHub metrics | Use GitHub REST repository metadata and stargazers_count for each distinct trusted owner/repo. Coalesce same-repo lookups. Follow canonical renames with safeguards. Track repo ID, URL, time, ETag and metric history. A 304 is usable only with the cached representation and linked validation time. No archived stars in the current metric field. | Use a free read-only credential for public repos, sequential requests per GitHub guidance and shared quota monitoring. Typical REST primary limits are 60/hour unauthenticated and 5,000/hour for standard authenticated users. 1,000 distinct repos consume about 16.7 unauthenticated hourly quota allocations, before retries. Check actual response headers. [Repository endpoint](https://docs.github.com/en/rest/repos/repos#get-a-repository) · [Limits](https://docs.github.com/en/rest/using-the-rest-api/rate-limits-for-the-rest-api) · [Best practices](https://docs.github.com/en/rest/using-the-rest-api/best-practices-for-using-the-rest-api) |

Respect each origin’s documented fetch cadence, including arXiv’s legacy API pacing. Prefer approved bulk metadata to broad sequential pagination. Resolve the actual archive file from the dataset card and pin its revision. Do not guess a download URL. For GitHub 403 distinguish rate-limited from denied; honor Retry-After or reset when exhausted. Anonymous 404 may mean unavailable/private. Quarantine; no fabricated zero.

## Five news publishers and five independent AI job boards

Each named source below has its own adapter configuration and health counter. Start with publisher-documented feeds/APIs if permitted. Otherwise follow public listing/detail URLs with per-source policy. Require a real detail-page sample, date evidence and complete permitted text before enabling a source. A secondary employer page can verify a job discovered on a board. Never double-count that employer site as another monitored job board.

| News discovery page | Extraction check |
| --- | --- |
| [MIT News AI](https://news.mit.edu/topic/artificial-intelligence2) | Separate original article from related stories. Check page time precision and source timezone. |
| [ScienceDaily AI](https://www.sciencedaily.com/news/computers_math/artificial_intelligence/) | Keep article publication time separate from study/source date. Inspect story boundaries. |
| [TechCrunch AI](https://techcrunch.com/category/artificial-intelligence/) | Compare labeled publication with modification timestamp. Record partial or restricted pages. |
| [Ars Technica AI](https://arstechnica.com/ai/) | Follow topic index to original reporting, handle teasers and time offsets. |
| [The Guardian AI](https://www.theguardian.com/technology/artificialintelligenceai) | Parse original timestamp, article body and liveblog exclusions. Check allowed access and reuse. |

| AI job board | Extraction check |
| --- | --- |
| [AIJobs.ai](https://aijobs.ai/) | Follow role detail to original requisition and verify datePosted. |
| [MoAIJobs](https://www.moaijobs.com/) | A “New” badge is discovery evidence only. Verify original date and AI role relevance. |
| [Inference Jobs](https://www.inferencejobs.com/) | Filter for evidenced AI work and trace the employer’s posting. Account for nontechnical roles at AI companies. |
| [AI Work Portal](https://aijobportal.com/) | Join curated link to employer posting. Deduplicate syndicated URLs and reject ambiguous dates. |
| [AI Community Jobs](https://www.aicommunityjobs.com/) | Check JS listing access, full employer description and original posting time. |

Possible replacements include another independently operated AI/ML job directory or the AI/ML section of a board with a documented feed, such as Himalayas with a strict job relevance filter. Prefer a dedicated AI board and record why any broader replacement meets the brief. For news, qualify an additional publisher AI desk before swapping. Record owner/domain, allowed route and fresh-data proof. Five independent successful scans per category are required; a blocked source counts as unavailable, never as a successful empty scan. Classify missing coverage as a release issue. [Himalayas RSS documentation](https://himalayas.app/docs/remote-jobs-rss)

## Providers and operator documentation

| Concern | Decision and reference |
| --- | --- |
| Free structured extraction | Check the free-eligible Gemini model and quota in the student’s actual account. Configure model ID, context and output caps; use structured output where supported. Count whole request tokens with a local compatible tokenizer or documented counter. Cache counts; any remote counting calls count in live budgets. [Pricing](https://ai.google.dev/gemini-api/docs/pricing) · [Limits](https://ai.google.dev/gemini-api/docs/rate-limits) · [Tokens](https://ai.google.dev/gemini-api/docs/tokens) |
| Second and third tiers | Choose an available Groq free-tier instruction model compatible with schema or JSON mode. Capture model ID from its catalog/account. Reserve shared per-model and organization budgets. Third tier is a locally installed Ollama instruction model with schema output; measure RAM/latency on the student’s machine. An unavailable tier is reported. The names in the employer’s chain are illustrative. [Groq limits](https://console.groq.com/docs/rate-limits) · [Groq models](https://console.groq.com/docs/models) · [Ollama structured output](https://docs.ollama.com/capabilities/structured-outputs) |
| Approved access | Read per-source policies and RFC 9309. Prefer publisher API, RSS, licensed dumps, mirrored metadata with provenance or explicit access. For JS, render permitted public pages with normal Playwright async and a readiness selector. Classify challenge pages even when HTTP 200. On a challenge, stop that route and record the alternative, cooldown and coverage impact. No challenge-solving dependency. [RFC 9309](https://www.rfc-editor.org/rfc/rfc9309) |
| Export and coordination | Batch fixed-range writes using RAW cell values. Pace requests and cap serialized body size. PostgreSQL queue claims use short row locks. [Sheets limits](https://developers.google.com/workspace/sheets/api/limits) · [Batch values](https://developers.google.com/workspace/sheets/api/reference/rest/v4/spreadsheets.values/batchUpdate) · [PostgreSQL SELECT](https://www.postgresql.org/docs/current/sql-select.html) |
| Cursor | Project rules in .cursor/rules/*.mdc, agents in .cursor/agents/*.md and prompt commands in .cursor/commands/*.md. Local subagents normally share the checkout. Use disjoint ownership and model inheritance. If a particular editor version hides commands, paste the command file in Agent. [Rules](https://cursor.com/docs/rules) · [Subagents](https://cursor.com/docs/subagents) · [Commands](https://cursor.com/changelog/1-6) · [Worktrees](https://cursor.com/docs/configuration/worktrees) |

**Per-source qualification record.** Maintain config/sources with source_id, canonical publisher, scope, documented access URL, policy URL and review date, allowed text use, original time field/timezone, pagination/stop rule, attribution, domain governor, fallback, reviewer and probe artifact. During B8 record fetch status, schema fingerprint, observed accepted fraction, sample date and rate-limit headers. Label configuration entries candidate, qualified or disabled; publish from qualified sources only.
